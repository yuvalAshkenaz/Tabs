Overview

Every .tabs-group works on its own, so you can place as many groups as you need on one page.

Features

ARIA roles, a roving tabindex, arrow keys, and a sideways-scrolling tab list. Make the window narrow to see the arrows.

Support

Questions and ideas are welcome on the live page.

1. Download the files

Download ytabs.min.css and ytabs.min.js (or copy them from the dist folder of this repository) and put them in your project. The readable sources are ytabs.css and ytabs.js. Both files are needed: the CSS styles the tabs and the arrows, and the script adds the scroll arrows and the drag support.

Add them to your page. The <script> goes at the end of the <body>, after the tabs markup.

<link rel="stylesheet" href="ytabs.min.css" />

<!-- ...your tabs HTML... -->

<script src="ytabs.min.js"></script>

2. Add the HTML

Wrap each set of tabs in .tabs-group. Inside it, put a ul.tabs-list with a button.tabs-btn in every li, and after the list one .tabs-div panel for every button, in the same order as the buttons. You can use as many groups as you need on a page.

<!-- Wrapper: one .tabs-group per set of tabs -->
<div class="tabs-group">

	<!-- Buttons: class tabs-list on the ul, class tabs-btn on every button -->
	<ul class="tabs-list" role="tablist">
		<li><button type="button" class="tabs-btn">First tab</button></li>
		<li><button type="button" class="tabs-btn">Second tab</button></li>
	</ul>

	<!-- Panels: class tabs-div, same order as the buttons -->
	<div class="tabs-div">
		<h3>First panel</h3>
		<p>Content of the first tab.</p>
	</div>

	<div class="tabs-div">
		<h3>Second panel</h3>
		<p>Content of the second tab.</p>
	</div>

</div>

The script adds the active class and all the aria-* attributes by itself. It also wraps the list in .tabs-nav, which holds the scroll arrows.

Use the arrow keys to move between tabs. When the tabs do not fit, swipe or drag the list, or use the arrows.
